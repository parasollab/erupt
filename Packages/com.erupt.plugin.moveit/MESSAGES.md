# Generated ROS messages — MoveIt plugin

`Runtime/Messages/Moveit/**` is generated by the ROS-TCP-Connector message browser
(`Robotics > Generate ROS Messages...`) and compiled into `Erupt.Plugins.MoveIt.Messages`.

| Source ROS package | Files | Generated from |
|---|---|---|
| `moveit_msgs` (msg + srv) | 100 | erupt_ws commit `f356be6` (ROS 2 host install of moveit_msgs) |

Regenerating: set the browser's output path to `Packages/com.erupt.plugin.moveit/Runtime/Messages`
before generating, so the files land in this assembly. `Assets/msgbrowser_settings.asset` is a
machine-local setting and is not the source of truth.

Do not generate `trajectory_msgs`, `sensor_msgs`, `shape_msgs`, `geometry_msgs`, `std_msgs`,
`octomap_msgs` or `object_recognition_msgs` here: the connector ships them in
`Unity.Robotics.ROSTCPConnector.Messages`, and duplicates produce CS0436 conflicts.
